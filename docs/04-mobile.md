# 04. 폰에서 쓰는 방법

유튜브를 폰으로 본다면, 이 도구의 도착점도 폰이다.  
PC에서 예쁘게 보고 영상은 폰에서 여는 분리는 실패다.

## 목표 동작

침대나 출퇴근 중에:

1. 텔레그램을 연다
2. `미국 국채 금리`를 보낸다
3. 2~4분 뒤 알림
4. 합의/갈림을 읽고
5. 의견이 다른 영상 2~3개만 유튜브 앱으로 연다
6. 나머지는 안 본다

“많이 찾아주는 것”이 아니라 **안 봐도 되는 영상을 줄이는 것**이 모바일 가치다.

## 1차: 텔레그램이 앱이다

설치 경험:

1. 봇을 연다 (QR 또는 링크 한 번)
2. 본인 계정만 허용되어 있다
3. 홈 화면에 봇 채팅을 고정한다

메시지 설계 (짧게):

```text
미국 국채 금리 · 14일 · 기사 6 · 영상 8

한 줄
10년물 상승 관측은 같고, 원인은 재정 vs 인플레로 갈림.

합의
• 10Y가 박스 상단
• 이번 주 입찰·CPI가 이벤트

갈림
A 발행 물량  B 인플레 재가속  C 터미널 프리미엄

[웹에서 전체 보기]
```

이어서 영상 카드가 하나씩:

```text
1/8  채널이름 · 14시간 전 · 18분 · 스탠스 A
핵심: 입찰 수요 부진이 커브를 가파르게 했다.
인용: "커버가 1.x까지 떨어졌다"

[유튜브]  [이 영상만 길게]
```

버튼은 두 개면 된다.

- `유튜브` → `https://youtu.be/VIDEO_ID` → 유튜브 앱
- `이 영상만 길게` → 타임스탬프 있는 3~5줄

기사는 접은 묶음으로. 폰에서 기사 8개를 펼치면 안 읽는다.

### 공유 시트 (두 번째 습관)

유튜브를 보다가 “이 사람 말이 맞나?”가 되면:

- 공유 → 텔레그램 → 봇
- 봇이 그 영상을 요약하고, **같은 키워드의 반대 의견 영상 2개**를 붙여 준다

키워드 검색과 이 흐름이 한 제품이다.  
필터 버블을 깨는 가장 강한 트리거는 “지금 보고 있는 영상”이다.

## 2차: PWA를 홈 화면에

봇으로 부족할 때:

- 스탠스 칩을 눌러 A만 / B만 보기
- 이미 본 영상 숨기기
- 지난 브리핑 히스토리
- 채널 뮤트 (“이 채널 일주일 숨김”)

iOS:

- Safari → 공유 → 홈 화면에 추가
- 푸시는 기대하지 않는다. 알림은 텔레그램

Android:

- Chrome 홈 화면 추가
- 웹 푸시도 가능하지만, 봇과 중복이니 굳이 안 넣어도 된다

화면은 한 손, 어두운 배경, 큰 탭 영역.  
데스크톱 레이아웃을 나중에 접지 말고 **처음부터 390px**로 짠다.

## 딥링크

| 목적지 | URL |
|---|---|
| 영상 | `https://youtu.be/{id}` |
| 특정 초 | `https://youtu.be/{id}?t=123` |
| 채널 | `https://www.youtube.com/channel/{id}` |
| 네이버 원문 | `originallink` |
| 구글 뉴스 | 리다이렉트 풀어서 원문 |

자막에서 주장을 뽑을 때 **초 단위**를 저장하면, 폰에서 해당 발언으로 바로 뛴다.  
긴 영상을 처음부터 보게 하면 이 도구를 안 쓰게 된다.

## 호스팅 — 폰이 닿게

봇과 PWA는 밖에서 호출되어야 한다.

| 방법 | 장점 | 단점 | 추천 |
|---|---|---|---|
| 집 PC + Cloudflare Tunnel | 공인 IP 불필요, 자막이 집 IP | PC가 꺼지면 죽음 | 시험용 |
| 작은 VPS (오라클 프리티어, 헤츠너) | 항상 켜짐 | 클라우드 IP라 유튜브 자막이 막힐 수 있음 | 본편 |
| VPS 엔진 + 집 자막 워커 | 역할 분리 | 구성이 조금 복잡 | **막히면 이걸로** |
| Railway / Render / Fly | 배포 쉬움, 요청이 몇 분 걸려도 프로세스가 살아 있다 | 슬립, IP 문제 | 폰에서 쓸 때 |
| Vercel | 밖에서 폰으로 연다. 로그인 없는 배포는 함수 60초라 영상 1개, 기사 1개 | 서버 디스크는 요청마다 갈린다. 리포트 HTML은 그 브라우저에 남긴다. Hobby로 받으면 300초까지 늘릴 수 있다. 공개 주소는 `RADAR_PASSWORD`가 맞을 때만 검색한다 | 지금 폰에서 여는 주소 |
| 이 컴퓨터의 localhost | 디버그에 가장 정확하다 | 폰은 같은 와이파이이고 서버가 켜져 있을 때만 | 개발 중 |

현실적인 안정 구성:

```text
폰 → 텔레그램 → VPS (엔진, 뉴스, LLM, 봇)
                ↘ 자막이 막히면 집 미니PC/노트북 워커
```

1차는 VPS 하나로 시작한다. 자막이 403이면 워커를 뺀다.  
처음부터 복잡한 홈서버를 짜지 않는다.

## 쓰지 않을 모바일 경로

- 카카오 알림톡: 검수, 사업자
- iOS 바로가기만으로 전체 파이프라인: 가능은 하나 디버그가 지옥
- Termux에 엔진을 올리는 것: 배터리를 태운다
- 앱스토어 출시: 혼자 쓰는 도구에 심사 비용

## 알림

기본은 **요청-응답**이다. 키워드를 보낸 뒤에만 일한다.

원하면 2차:

- 저장 키워드 3개 (`미국 국채`, `원달러`, `AI 전력`)
- 매일 07:30 다이제스트
- “어제 이후 스탠스가 갈린 주제만”

푸시 남발은 안 읽힌다. 다이제스트는 한 통, 한 줄 + 링크.

## 오프라인

비행기에서 이미 받아 둔 브리핑은 PWA 캐시로 읽을 수 있다.  
새 검색은 온라인이 필요하다. 자막·기사 수집을 폰에서 직접 하지 않는다.

## 성공 기준 (모바일)

일주일 써 보고 이것이면 성공이다.

- 유튜브를 열기 **전에** 이 봇을 연다
- 한 세션에 영상 10개가 아니라 2~3개만 본다
- “평소 안 보던 채널”이 매주 하나 이상 클릭된다
- 큰 채널만 보는 습관이 줄었다고 느껴진다
