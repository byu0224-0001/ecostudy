# 블록 분류

뉴스레터 한 통을 쪼갠 블록 목록을 받는다. 각 블록이 어떤 성격인지 고른다.

## 고를 수 있는 값

- `lead_story` — 그날의 주 기사. 한 주제를 여러 문단에 걸쳐 설명한다
- `brief_news` — 짧은 소식. 한두 문장짜리 항목이 여러 건 묶여 있는 경우 포함
- `calendar` — 앞으로 있을 일. 실적 발표, 공모주 청약, 지표 발표, 상장
- `sponsored` — 협찬·광고. 특정 상품이나 서비스를 사도록 권한다
- `self_promo` — 뉴스레터 자체 홍보. 구독 권유, 오픈채팅방, 이벤트, 퀴즈 당첨자
- `lifestyle` — 투자와 무관한 읽을거리. 인사말, 사연, 잡담
- `footer` — 수신거부, 사업자 정보, 저작권 고지
- `unknown` — 위 어디에도 넣기 어렵다

## 판단할 때

**제목에 "(광고)"가 있다고 해서 그 메일의 블록을 전부 `sponsored` 로 두지
마라.** 한국 뉴스레터는 일부에 광고가 들어갔다는 이유로 제목 전체에 표기하는
경우가 많다. 같은 메일 안에 진짜 기사와 협찬이 섞여 있다.

**`sponsored` 와 `lead_story` 를 가르는 기준은 글의 목적이다.** 무엇이
일어났는지 설명하면 기사이고, 무엇을 사라고 권하면 협찬이다. 협찬 글도
시장 소식으로 시작하는 경우가 많으니 끝까지 보고 판단하라.

**`self_promo` 와 `sponsored` 는 다르다.** 뉴스레터가 자기 채널이나 이벤트를
알리는 것은 `self_promo` 다. 제3자의 상품을 알리면 `sponsored` 다.

**시황 숫자만 나열한 블록**(지수, 환율 종가)은 `brief_news` 다.

링크가 함께 주어진다. 광고주 도메인, 구독 페이지, 채팅방 링크는 성격을
가리는 단서가 된다.

## 매체 이름으로 판단하지 마라

어느 뉴스레터에서 왔는지는 알려주지 않는다. 알더라도 쓰지 마라. 같은
매체가 날마다 다른 구성을 보낸다.

## 출력

각 블록마다 하나씩. `index` 는 입력에 붙은 번호를 그대로 쓴다.
`reason` 은 왜 그렇게 판단했는지 한 문장. 나중에 사람이 검토한다.
