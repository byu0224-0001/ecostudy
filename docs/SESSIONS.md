# 회차 이력

`sessions/S-###.yaml` 하나가 회차 하나다. 후보 풀이 "무엇을 할까"를 담는다면
여기는 **"무엇을 했나"**를 담는다.

이게 없으면 두 가지가 무너진다. 반년 뒤 "작년에 하지 않았나"를 기억에
의존하게 되고, 6축 배분 규칙이 문서에만 남는다. 26회를 돌리면 반드시 걸린다.

## 결론을 적지 않는다

가장 중요한 결정이다. 회차 기록에 `conclusion` 필드를 두지 않고, 후보에서
막아둔 결론 필드를 여기서도 똑같이 거부한다. 한쪽만 막으면 우회로가 된다.

이 모임의 목적은 답을 내는 것이 아니라 각자 자기 기준을 세우는 것이다.
"결론: 엔캐리 청산 위험은 제한적"이라고 적는 순간 그 회차는 발표가 되고,
다음에 그 주제를 다시 볼 때 이미 답이 있으니 볼 필요가 없어진다.

대신 셋으로 나눈다.

| 필드 | 내용 | 검사 |
|---|---|---|
| `settled` | 그 자리에서 사실로 합의된 것 | 각 항목에 `source` 필수 |
| `split` | 갈린 지점과 각 입장 | **비어 있으면 잡는다** |
| `open` | 못 푼 것 | **비어 있으면 잡는다.** 각 항목에 `why` 필수 |

**깨끗하게 합의된 회차는 잘된 게 아니라 의심스러운 것이다.** 아무도 갈리지
않았다면 주제 선정이 틀렸거나 아무도 반대하지 않은 것이다.

`open`이 비어 있어도 잡는다. 다 풀렸다는 것은 대개 한 단계 덜 판 것이고,
실무적으로는 **후보 유입이 끊긴다**는 뜻이다. `open`이 다음 회차의 재료다.

```bash
python3 cli.py sessions open      # 전 회차의 미해결 질문 모음
```

## 배치 — 다음 회차에 어느 축을 할 것인가

```bash
python3 cli.py sessions balance
```

`docs/TOPICS.md`의 배치 규칙을 실제 이력에 대고 검사한다. 규칙을 문서에만
두면 반년 뒤에는 지켜지지 않는다.

- 직전 회차와 같은 축 금지
- 4·5·6축 분기 1회 이상 — 목적함수에 가장 직접적인데 데이터가 적다는
  이유로 계속 밀린다. 그래서 먼저 올린다
- 1축 분기 1회 이상 — 공통 좌표가 없으면 나머지 대화가 흩어진다
- 독서 8주 이내

출력은 권장 축과 금지 축이다. **축을 먼저 좁히고 그 안에서 정렬 기준으로
고른다.** 반대로 하면 항상 1축이 이긴다.

## 중복 — 이미 다룬 것인가

```bash
python3 cli.py sessions similar "외국인 자금이 대만으로 이동했다"
python3 cli.py sessions similar --topic T-002
```

`topics check`를 돌릴 때도 자동으로 뜬다. 승격을 고민하는 시점이 중복을
알아야 할 시점이기 때문이다.

### 어떻게 재는가

**자카드가 아니라 포함률이다.** 묻는 것은 "이 주장이 이미 다뤄졌나"이지
"두 글이 얼마나 닮았나"가 아니다. 회차 기록은 제목·질문·갈린 지점·미해결까지
담아 토큰이 수십 개인데 주장은 열 개 남짓이라, 합집합으로 나누면 여섯 개가
겹쳐도 점수가 바닥에 깔린다. 첫 구현이 이 실수로 엔캐리 회차와 엔화 개입
주장을 못 잡았다.

**조사를 뗀다.** 형태소 분석기를 붙이지 않는 대신 "엔캐리와 → 엔캐리",
"대만으로 → 대만" 정도만 처리한다. 어간이 두 글자 미만이 되면 떼지 않는다
— "물가"에서 '가'를 떼면 남는 것이 없다. 완전하지 않지만 대부분의 명사구를
맞춘다. 이것도 첫 구현이 놓쳐서 테스트가 잡았다.

**숫자보다 겹친 말을 보여준다.** 열 단어짜리 문장 둘이 흔한 말 두 개를
공유하는 것과 고유한 말 두 개를 공유하는 것은 전혀 다른데 점수는 같다.
`겹친 말 엔화, 엔캐리`를 보면 사람이 0.3초에 판단하고 `겹친 말 미국, 시장`을
보면 무시한다. 문턱을 정교하게 맞추려 애쓰는 것보다 낮게 잡고 판단을 사람에게
넘기는 편이 낫다.

**자동으로 거르지 않는다.** 겹치는 것이 반복인지 후속인지는 사람만 안다.
같은 주제를 반년 뒤에 다시 보는 것은 좋은 일이고, 모르고 하는 것만 문제다.

## 순환

```
피드 훑기 → 주장 포착 → 지표 대조 → 승격 → 배치 규칙으로 축 결정
                ↑                                    ↓
                └────── 회차의 open ←───── 회차 진행 ──┘
```

`open`이 다음 후보가 되는 고리가 닫히면 후보 풀은 스스로 채워진다. 그
전까지는 피드와 참가자 제안으로 채운다.

## 기록 시점

회차가 끝난 다음 날. `settled`와 `split`은 그날 안에 적어야 한다. 일주일
지나면 갈렸던 지점이 뭉개져서 "대체로 이런 얘기였다"가 된다. 그러면 기록의
가치가 사라진다.
