# 08. 리포트 화면

읽는 화면은 폰 너비부터 잡는다. 데스크톱은 같은 카드를 가로로 펼친 것이다.

시각 기준은 저장소 루트의 [design.md](../design.md)다. 글자는 Pretendard만 쓴다. 카드는 12px, 주요 버튼은 화면마다 라임 하나다.

## 위부터

1. **세이지 히어로.** 키워드가 헤드라인이다. 기간, 후보 수, 채택 수, 한 줄.
2. **잉크 카드 하나.** “이번 목록이 일부러 벌린 관점”. 제품 문장을 여기 둔다.
3. **쟁점.** 모바일은 카드, 넓은 화면은 표. 행을 누르면 그 논점의 영상만 남는다.
4. **영상.** 채택분 전부. 필터: 전체 / 상승 압력 / 하락 압력 / 범위·구조.
5. **기사·칼럼.** 뉴스와 칼럼 배지를 분리.
6. **다크 푸터.** 출처의 함의는 조언이 아니라는 한 줄.

## 영상 카드

모바일은 위아래, 768px 이상은 왼쪽 썸네일 280px.

| 요소 | 내용 |
|---|---|
| 썸네일 | 16:9. 재생 시간 배지. 구현 시 `i.ytimg.com/vi/{id}/hqdefault.jpg` |
| 배지 | 상승 압력 / 하락 압력 / 범위·구조 |
| 메타 | 채널, 게시일, 길이 |
| 원제목 | 번역하거나 줄이지 않음 |
| 키워드 | 필. 검색어가 아니라 이 영상에서 뽑은 말 |
| 의견 | `summary`. 두세 문장 |
| 다른 점 | `delta`. 세이지 또는 연녹 면으로 구분 |
| 인용 | 타임스탬프 + 원문 한 줄. 누르면 `t=` 초로 이동 |
| 버튼 | 라임 필. 유튜브 앱으로 연다 |

`delta`가 비어 있으면 칸을 그리지 않는다. “다른 점이 없습니다”라고 채우지 않는다.

썸네일 옆에 의견을 붙이는 이유는 제목만 보고 또 큰 채널을 고르는 행동을 막기 위해서다. 제목은 원문 그대로 두되, 판단은 제목 아래 의견과 다른 점이 하게 한다.

## 상태

- `sample: true`이면 히어로 아래에 “예시 데이터” 배지를 둔다.
- 자막 실패로 빠진 영상은 카드를 만들지 않는다. 히어로 보조 문구에 “자막 없음 N개는 제외”만 적는다.
- 쟁점이 `incomparable`이면 표에 넣지 않고, 접힌 “같은 명제로 붙지 않은 말”에 둔다.
